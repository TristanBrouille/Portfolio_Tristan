# Portfolio — Tristan Dhersin

Site portfolio personnel : ingénieur développeur web full-stack (Java / Spring Boot & Angular).

Site statique en **HTML, CSS et JavaScript** sans dépendance ni build.

## Contenu

- Présentation et recherche de stage de fin d'études (6 mois, dès le 25 janvier 2027)
- Parcours : expériences professionnelles et formation (onglets)
- Projets filtrables : web, DevOps & sécurité, IA, mobile, IoT & embarqué
- Engagement associatif (EPF Astronomie)
- Compétences et langues
- Contact + CV en PDF

## Fonctionnalités

- Thème clair / sombre (mémorisé)
- Responsive (menu mobile)
- Animations au scroll, compteurs, effet machine à écrire (désactivés si `prefers-reduced-motion`)
- Version imprimable

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
npx serve .
```

## Déployer sur GitHub Pages

Settings → Pages → Source : `Deploy from a branch` → branche `main`, dossier `/ (root)`.
Le site sera disponible sur `https://tristanbrouille.github.io/Portfolio_Tristan/`.
